# Voxel Velocity (Three.js)

ローカルで `index.html` をブラウザで開くだけで動作します。

## 実装済み要素
- シングルレース固定（3周、1P + CPU7）
- レース前フロー: Track(8) / Character(8) / Difficulty(3) / Mirror / Clone / Start
- オプションメニュー
- レース中ポーズメニュー（Resume/Restart/Exit）
- 反応の良いハンドリング + 壁への軽接触 + ドリフトチャージ & 3段階ブースト
- アイテム8種（同時所持1つ）
- 順位連動の控えめな配布
- AI: 難易度プリセット、複数レーンで追い越し、ハザード回避、ドリフトゾーン利用
- HUD: 順位/ラップ/最終ラップ表示、ミニマップ、アイテムスロット、タイマー/スプリット
- オーディオ: 可読性重視SFX + トラックごとの簡易ループ
