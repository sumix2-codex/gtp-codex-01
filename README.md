# Web出退勤システム

30人程度の社員が共有端末やタブレットから簡単に打刻できる、静的Webアプリのサンプルです。フロント画面で社員を選び、出勤または退勤ボタンを押すと、日本時間（JST）の日時で打刻します。Google Apps Scriptを経由してGoogleスプレッドシートへログを追記できます。

## 主な機能

- 日本時間で自動更新される大きな日付・デジタル時計
- 10人ずつ3ブロックに分けた社員選択ボタン
- 出勤・退勤だけの大きな打刻ボタン
- 打刻時刻を画面更新なしで取得
- 別画面の管理画面（`#admin`）と簡易ログイン認証
- 管理画面から以下を設定
  - Apps Script WebアプリURL
  - GoogleスプレッドシートID
  - 任意のAPI共有シークレット
  - 管理パスワード
  - グループ名・社員名の追加、変更、削除
- Google連携未設定時や通信失敗時のローカルバックアップ保存

## ファイル構成

```text
.
├── index.html                 # 画面のHTML
├── styles.css                 # UIスタイル
├── app.js                     # 時計、打刻、管理画面、設定保存処理
├── manifest.webmanifest       # ホーム画面追加用のWebアプリ設定
├── icon.svg                   # ホーム画面用アイコン
└── google-apps-script/
    └── Code.gs                # Google Apps Script側の受信・Sheets追記処理
```

## ローカルでの起動

静的ファイルだけで動作します。任意のHTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。


## iPadでローカルアプリ風に開く方法

このアプリはiPadにインストールするネイティブアプリではなく、Safariの「ホーム画面に追加」を使ってローカルアプリ風に起動するWebアプリです。iPadのホーム画面から全画面に近い見た目で開けます。

### 重要な前提

- iPad単体でこのリポジトリのHTMLファイルを安定運用するのではなく、同じWi-Fi内のPC/MacからHTTP配信してiPadで開く方法を推奨します。
- `file://` で直接 `index.html` を開く方法は、ブラウザの制限によりGoogle Apps Script送信や保存挙動が不安定になることがあるため推奨しません。
- Googleスプレッドシートへ打刻を送るには、iPadがインターネットに接続できる必要があります。
- iPad側の社員設定や管理画面設定は、そのiPadのSafari内に保存されます。複数iPadで同じ設定を使う場合は、それぞれのiPadで設定してください。

### 手順1: PC/Macでアプリを配信する

PC/Macでこのフォルダを開き、HTTPサーバーを起動します。

```bash
cd /path/to/gtp-codex-01
python3 -m http.server 8080 --bind 0.0.0.0
```

起動したPC/MacのローカルIPアドレスを確認します。例としてIPアドレスが `192.168.1.20` の場合、iPadで開くURLは次のようになります。

```text
http://192.168.1.20:8080/
```

macOSでは、以下のコマンドでWi-FiのIPアドレスを確認できます。

```bash
ipconfig getifaddr en0
```

Windowsでは、PowerShellまたはコマンドプロンプトで以下を実行し、Wi-FiアダプターのIPv4アドレスを確認します。

```powershell
ipconfig
```

### 手順2: iPadのSafariで開く

1. iPadをPC/Macと同じWi-Fiに接続します。
2. Safariで `http://<PCまたはMacのIPアドレス>:8080/` を開きます。
3. 出退勤画面が表示されることを確認します。
4. 右上の「管理画面」から初期パスワード `admin1234` でログインします。
5. Apps Script WebアプリURL、GoogleスプレッドシートID、必要に応じてAPI共有シークレットを保存します。

### 手順3: ホーム画面に追加する

1. Safari下部または上部の共有ボタンを押します。
2. 「ホーム画面に追加」を選びます。
3. 名前を「出退勤」などにして追加します。
4. 次回からはホーム画面のアイコンをタップして起動します。

`index.html` にはiPadのホーム画面起動向けメタタグを設定済みで、`manifest.webmanifest` と `icon.svg` も同梱しています。

### 手順4: 当日の運用

1. PC/Mac側でHTTPサーバーを起動したままにします。
2. iPadのホーム画面から「出退勤」を開きます。
3. 社員名を選択し、「出勤」または「退勤」を押します。
4. Google連携が設定済みであれば、打刻データはApps Script経由でスプレッドシートに追記されます。

### よくあるトラブル

| 症状 | 確認すること |
| --- | --- |
| iPadでページが開けない | iPadとPC/Macが同じWi-Fiか、URLのIPアドレスとポート番号が正しいか、PC/Macのファイアウォールが遮断していないか確認してください。 |
| ホーム画面アイコンから開くと表示されない | PC/Mac側のHTTPサーバーが起動しているか確認してください。 |
| 打刻がスプレッドシートに入らない | 管理画面のApps Script WebアプリURL、スプレッドシートID、共有シークレット、Apps Scriptのデプロイ権限を確認してください。 |
| iPadを変えたら社員設定が消えた | 設定はiPadごとのSafariに保存されます。新しいiPadでも管理画面から設定してください。 |

## 初期管理ログイン

1. 画面右上の「管理画面」を押します。
2. 初期パスワード `admin1234` でログインします。
3. 本番運用前に必ず管理パスワードを変更してください。

> 注意: このサンプルの管理認証と設定値はブラウザの `localStorage` / `sessionStorage` に保存されます。社外公開や厳格な認証が必要な本番環境では、サーバー側認証・権限管理へ置き換えてください。

## Googleスプレッドシート連携手順

1. Googleドライブで集計先のスプレッドシートを作成します。
2. スプレッドシートURLからIDを控えます。
   - 例: `https://docs.google.com/spreadsheets/d/<ここがID>/edit`
3. Google Apps Scriptプロジェクトを作成し、`google-apps-script/Code.gs` の内容を貼り付けます。
4. 任意でApps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に以下を追加します。
   - キー: `ATTENDANCE_API_SECRET`
   - 値: 任意の共有シークレット
5. Apps ScriptをWebアプリとしてデプロイします。
   - 実行ユーザー: 自分
   - アクセスできるユーザー: 運用方針に合わせて選択
6. WebアプリURLを控えます。
7. 本アプリの管理画面で、WebアプリURL、スプレッドシートID、共有シークレットを保存します。

## スプレッドシートに作成される列

Apps Scriptは `出退勤ログ` シートを自動作成し、以下の列で追記します。

| 列 | 内容 |
| --- | --- |
| タイムスタンプ | `YYYY-MM-DD HH:mm:ss` 形式のJST時刻 |
| 日付 | 打刻日 |
| 時刻 | 打刻時刻 |
| 種別 | 出勤または退勤 |
| 社員ID | ブラウザ設定内の社員ID |
| 社員名 | 管理画面で設定した社員名 |
| グループID | ブラウザ設定内のグループID |
| グループ名 | 管理画面で設定したグループ名 |
| タイムゾーン | `Asia/Tokyo` |
| ユーザーエージェント | 打刻端末のブラウザ情報 |

## 運用上の補足

- 共有端末で利用する場合、管理画面は使用後にログアウトしてください。
- CORS制約を避けるため、フロントからApps Scriptへの送信は `no-cors` で行っています。そのためブラウザ側ではApps Scriptの詳細なレスポンス本文は確認できません。
- 打刻は送信前に最大300件までローカルバックアップされます。Google連携が未設定でも、ブラウザ内には直近の打刻が残ります。
- 複数端末で社員設定を共有したい場合は、設定管理もサーバー側またはスプレッドシート側に移す拡張を推奨します。
